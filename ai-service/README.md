# 🧠 MediSlot AI/ML Microservice

This directory is reserved for the Python FastAPI microservice that will power:
1. **AI Medical Document Summarizer** (Phase 6): OCR/PDF extraction and clinical summary generation for clinicians.
2. **ML No-Show Predictor** (Phase 7): Machine learning model trained with scikit-learn on historical booking attributes (lead days, time of day, prior cancellation rates, weather, distance).
3. **Admin Assistant** (Phase 8): RAG-backed clinic operations assistant using pgvector.

### Prerequisites (for upcoming phases)
- Python 3.10+
- FastAPI, Uvicorn, scikit-learn, Pandas, OpenAI SDK
