# 🧪 MediSlot Test Suite

This directory will contain the end-to-end integration and smoke test suites for MediSlot.

### Planned Test Frameworks (Phase 9)
- **Vitest**: Unit and component tests for React client and Node services.
- **Playwright**: Cross-browser End-to-End (E2E) automation covering patient booking, doctor dashboard schedule editing, and admin invoicing.
- **Supertest**: API integration tests for Express server endpoints.
